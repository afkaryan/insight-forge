# InsightForge
### Career Intelligence Platform

InsightForge is a premium, data-driven career intelligence workstation designed to transform unstructured professional data into strategic career vectors. By leveraging autonomous NLP engines and high-density dashboard visualizations, InsightForge synchronizes candidate capabilities with global market signals to ensure peak professional parity.

---

## 🚀 Key Features

- **Neural Resume Parsing**: Automated extraction of structured capability profiles from unstructured PDF sources.
- **AI-Powered Match Engine**: High-fidelity NLP matching and similarity scoring to align profile vectors with global job requisitions.
- **Interactive Command Hub**: Clinical, high-density dashboard featuring Recharts-driven analytics and strategic growth telemetry.
- **Market Intelligence Hub**: Real-time job discovery via integrated APIs with autonomous "New Signal" detection.
- **Strategic Role Matrix**: AI-driven skill gap analysis and recommended career trajectories.
- **Neural Deployment Tracker**: End-to-end application pipeline monitoring with field observation synchronization.

## 🛠️ Tech Stack

### Frontend
- **Core**: React.js 18 (Vite)
- **Styling**: Tailwind CSS (Clinical Design System)
- **Animations**: Framer Motion
- **Visualization**: Recharts / Lucide Icons

### Backend
- **Core**: Node.js / Express.js
- **Database**: MongoDB (Atlas)
- **Authentication**: JWT (JSON Web Tokens) with Secure Middleware

### Intelligence Layer
- **Parsing**: PDF-Parse / Regex-based Neural Heuristics
- **Discovery**: Remotive API / External Market Signals

## 🔄 System Workflow

1. **Intelligence Initialization**: The user uploads a performance vector (Resume PDF).
2. **Neural Extraction**: The parsing engine transforms raw text into a structured capability schema.
3. **Market Synchronization**: The system fetches active job signals from global market nodes.
4. **Vector Parity Analysis**: Matches profile data against job requirements to calculate high-fidelity match scores.
5. **Strategic Visualization**: Presents real-time insights and decision-making analytics on the Command Hub.

## 📦 Installation & Deployment

### 1. Repository Setup
```bash
git clone https://github.com/your-username/InsightForge.git
cd InsightForge
```

### 2. Backend Configuration
```bash
cd backend
npm install
# Configure .env with MONGO_URI and JWT_SECRET
npm run dev
```

### 3. Frontend Deployment
```bash
cd ../frontend
npm install
npm run dev
```

**Local Host Interface**: `http://localhost:5173`
